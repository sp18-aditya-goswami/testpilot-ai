# Design: TestPilot

The locked system. Every Hallmark run reads this first and the screens share it. Change it on purpose; the file is the rule.

## System
- Genre: modern-minimal
- Shape: app screens (new test, plan review, run, runs)
- Theme: Vantage, colourway steel, no point cloud (app scope)
- Axes: dark/grotesk-sans/chromatic-lime · posture: restrained

## Controls
- One lime primary pill per screen; secondaries are hairline pills. Lime marks only the primary action, the current step and the will-run figure. Checkboxes are ink, never lime.
- Status is coloured text with one icon: passed teal, failed coral, error amber, skipped muted. Severity uses the same three colours.
- Colour means outcome, severity or Claude's authorship and nothing else: HTTP methods and documented status codes are ink (a 5xx stays coral, because it is a failure). `--color-ai` marks only what Claude wrote or explained.
- Code, requests and responses sit in dark wells (`.graphite`), never wrapped.

## Provenance
Every case and every explanation says who made it, with `components/Source.tsx`:
- **Claude** (AI-generated, spark icon, `--color-ai`): proposed by Claude, validated before it runs.
- **Contract** (system-generated, table icon): derived from the OpenAPI schema by TestPilot's rules.
- **Fuzzing** (system-generated, dice icon): generated by Schemathesis.
- **Written by you** (pencil icon): saved requests and hand-added cases.
`SourceLegend` spells these out once per screen; explanations carry `ExplainedBy` (Claude or TestPilot rules).

## Brand
The mark (`components/Logo.tsx`) is a measuring frame drawn only at its corners, a probe path inside it, and one lime point where it finds something. The wordmark is Geologica 500, tracked -0.035em.

## Navigation
Sidebar: Overview, Environments, Run history, then API specs (each opens its contract page), then Collections. Every screen under a project opens with `Breadcrumbs` (project, collection or spec, suite, plan, run). The theme switch offers light and dark only.

## Composition
- Every flow screen opens with the three-step rail (`components/Steps.tsx`).
- Groups climb the surface ladder: hairline rows inside a `.panel` on the paper; no card inside a card.
- Counts are drawn once as the outcome bar (`components/OutcomeBar.tsx`) with the numbers spelled out.
- The run's verdict is one measured figure inside corner ticks (`.ticks`).

## Motion
`transform` and `opacity` only, `--dur-micro` and `--dur-short`; no reveals; everything still under reduced motion.
